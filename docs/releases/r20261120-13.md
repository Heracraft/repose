## One trap met on the way, because it will be met again

The Playwright suite failed every test in `auth.spec.ts` and
`billing.spec.ts` at exactly 30.1 s, which reads as sign-in and billing
being broken. Neither was. A suite killed minutes earlier had left its
`node build` listening on the test port, `pkill -f "playwright test"`
having taken the runner and not the fixtures, so the second run's tests
talked to the first run's dashboard whose api was gone. `ss -ltnp` named
the holding pid in one line. After killing both runs' fixtures the same
suite was 422 green. ENG-10 carries the fix: a bound port should be an
error naming the holder, not a silent reuse. **The tell is the identical
timeout across a whole file; a real failure varies.**
